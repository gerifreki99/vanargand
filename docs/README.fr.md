# Documents de conception

Sous licence CC-BY-4.0. Voir `../LICENSE-DOCS`.

Déposez ici le corpus existant. Organisation suggérée :

```
docs/
  01-concept.pdf          Concept et vision
  02-scope.pdf            Périmètre, feuille de route, portes
  03-threat-model.pdf     Modèle de menace
  04-proof-of-service.pdf Consensus et pondération au mérite
  05-emission.pdf         Émission du jeton
  06-distribution.pdf     Distribution initiale, cohorte de lancement
  07-simulation.pdf       Cahier de simulation économique
  revisions/
    R1.pdf                Premier tour de revue adversariale
    R2.pdf                Deuxième tour de revue
```

Les noms de fichiers restent en anglais dans les deux versions du README — ce
sont des identifiants pour un dossier `docs/` unique, pas du contenu à
traduire. Seul le contenu des documents eux-mêmes est en français (voir
[`TRADUCTIONS.md`](../TRADUCTIONS.md)).

Les sources markdown restent privées pendant la rédaction ; les PDF ci-dessus
sont la forme publiée.

Les journaux de révision sont conservés comme documents distincts plutôt que
repliés silencieusement dans la conception. Ils consignent deux décisions prises,
jugées fausses, puis remplacées. Ils sont publiés délibérément.
