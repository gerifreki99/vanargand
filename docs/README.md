# Design documents

Licensed under CC-BY-4.0. See `../LICENSE-DOCS`.

Place the existing corpus here. Suggested organisation:

```
docs/
  01-concept.pdf          Concept and vision
  02-scope.pdf            Scope, roadmap, gates
  03-threat-model.pdf     Threat model
  04-proof-of-service.pdf Consensus and merit weighting
  05-emission.pdf         Token emission
  06-distribution.pdf     Initial distribution, launch cohort
  07-simulation.pdf       Economic simulation notebook
  revisions/
    R1.pdf                First adversarial review round
    R2.pdf                Second review round
```

The revision logs are kept as separate documents rather than folded silently
into the design. They record two decisions that were made, found to be wrong,
and replaced. They are published deliberately.

Source markdown is kept private during drafting; the PDFs above are the
published form. Filenames stay in English in both language versions of this
README — see [`TRADUCTIONS.md`](../TRADUCTIONS.md).
